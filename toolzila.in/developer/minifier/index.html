HTML, CSS & JS Minifier

Minify HTML, CSS and JavaScript to reduce file size. See how many bytes you save.

How to use HTML, CSS & JS Minifier

  1. Choose HTML, CSS or JavaScript.
  2. Paste your code.
  3. Click Minify, then copy or download the smaller code.

Features

  • Three languages in one tool
  • Shows the size saved
  • JavaScript minified with Terser

Supported formats and limitations

HTML minifying keeps inline script, style, pre and textarea blocks unchanged. CSS minifying also removes extra spaces inside quoted text, so check content strings. Always test minified code before using it live.

Frequently asked questions

Is minified code safe to use?

Usually yes, but test it. Keep your original file as a backup.

Is my code uploaded?

No. Minifying happens in your browser.

Privacy: this tool runs in your browser. Nothing you add is uploaded to our servers.
