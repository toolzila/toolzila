QR Code Generator

Create a QR code for any link or text and download it as a PNG image.

How to use QR Code Generator

  1. Type or paste a link or text.
  2. Choose the size and colour.
  3. Click Download PNG.

Features

  • Any link or text
  • Sizes up to 1024 px for print
  • Custom colour

Supported formats and limitations

Very long text cannot fit in a QR code. Use dark colours on a light background so it scans reliably. Always test the code with your phone before printing.

Frequently asked questions

Does a QR code expire?

No. It simply stores your text or link.

Is my link sent anywhere?

No. The code is made in your browser.

Privacy: this tool runs in your browser. Nothing you add is uploaded to our servers.
