Base64 Encoder & Decoder

Encode text to Base64 or decode Base64 back to text. Supports UTF-8 text, URL-safe Base64 and converting a file to a data URL.

How to use Base64 Encoder & Decoder

  1. Type text and click Encode to Base64, or paste Base64 and click Decode.
  2. Tick URL-safe if you need Base64 for links or tokens.
  3. To convert a file, choose it and copy the data URL.

Features

  • UTF-8 and Hindi text supported
  • URL-safe option
  • File to data URL (up to 5 MB)

Supported formats and limitations

Decoding works for text. If the Base64 stores a file such as an image, the decoder shows a message instead. Base64 is not encryption, so do not use it to hide secrets.

Frequently asked questions

Is Base64 secure?

No. It only changes how data is written. Anyone can decode it.

Why does decoding show an error?

The text may not be valid Base64, or it may hold a file instead of text.
