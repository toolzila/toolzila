How to use SIP Calculator

  1. Enter your monthly investment.
  2. Enter the expected yearly return and the time in years.
  3. Read the invested amount, returns and total value.

Features

  • Instant results
  • Invested vs returns bar
  • Handles 0 percent return

Supported formats and limitations

Returns are estimates. Real market returns change and can be lower or higher, and fees and taxes are not included.

How it works

FV = P x ((1+i)^n - 1) / i x (1+i), where P is the monthly amount, i is the monthly return (yearly rate / 12 / 100) and n is the number of months. Example: Rs 5,000 a month at 12 percent for 10 years grows to about Rs 11.6 lakh.

Frequently asked questions

Is the return guaranteed?

No. It is only an estimate based on the rate you enter.

Does it include taxes?

No. Add them separately.
